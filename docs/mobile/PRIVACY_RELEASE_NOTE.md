# Play 공개 개인정보 연락처 준비 메모

현재 웹 개인정보처리방침의 프로젝트 문의 경로는 공개 [GitHub Issues](https://github.com/byStander9/kor-hot-and-cold/issues/new)입니다. 아직 사용자가 공개 연락 이메일을 확정하지 않았기 때문에 임의의 이메일 주소를 게시하지 않았습니다.

Play Console 출시 전 사용자가 직접 다음을 완료해야 합니다.

- 스토어 등록정보에 표시할 공개 연락 이메일을 확정한다.
- `/privacy`의 문의처와 Play Console의 공개 연락처가 서로 일치하도록 갱신한다.
- 공개 GitHub Issue에는 이름, 이메일, IP 주소 등 개인정보를 작성하지 말라는 안내를 유지한다.
- 실제 배포 시점의 SDK, 서버 로그, 광고·분석·푸시 사용 여부가 이 방침과 같은지 다시 확인한다.

코드 또는 운영 방식이 바뀌어 회원가입, 광고, 분석, 푸시 알림, 별도 서버 로그나 데이터베이스가 추가되면 개인정보처리방침과 Play Data safety 응답을 함께 갱신해야 합니다.
