# 한국어 Hot and Cold 모바일 디자인 명세

> 상태: 모바일 MVP 구현 기준<br>
> 대상: Android 우선, Expo/React Native, 360–430dp 세로 화면<br>
> 기준: 웹 MVP의 크림색 종이 배경, hot/cold 색상, 정확한 순위 중심 정보 구조를 계승한다.

## 1. 제품 목표

사용자는 숫자 시드로 정해진 비밀 단어를 추측하고, 각 단어의 의미 근접 순위를 따라 정답에 접근한다. 모바일 앱은 한 손으로 빠르게 단어를 반복 입력하는 흐름을 최우선으로 하며 다음 기능을 제공한다.

- 랜덤 시드로 새 게임 시작
- 특정 시드를 직접 열고 친구와 같은 문제 플레이
- 단어 추측, 순위 확인, 최고 기록 갱신
- 현재 최고 순위보다 더 가까운 적응형 힌트 최대 3회
- 포기 후 정답 확인
- 시드별 진행 상태 복원
- 정답 또는 포기 후 결과 공유와 전체 순위 탐색

첫 MVP에는 계정, 광고, 푸시 알림, 온라인 리더보드가 없다. 게임 API 서버 연결은 필수이며 오프라인 플레이는 지원하지 않는다.

## 2. 디자인 원칙

1. **입력은 항상 손가락 가까이에 둔다.** 게임 진행 중 입력기는 화면 아래에 고정하고 키보드가 열려도 가리지 않는다.
2. **순위가 가장 중요한 정보다.** 온도 장식보다 정확한 순위 숫자를 크게 보이고, 추측 목록은 항상 1위에 가까운 순서로 정렬한다.
3. **색만으로 뜻을 전달하지 않는다.** 온도 색과 함께 한글 라벨, 순위, 온도계 아이콘 또는 왼쪽 강조선을 사용한다.
4. **다음 행동을 한 번에 하나만 강조한다.** 플레이 중에는 `추측`, 종료 후에는 `랜덤 새 게임`이 유일한 주 버튼이다.
5. **기존 웹의 차분한 인상을 유지한다.** 크림색 바탕, 밝은 표면, 얇은 선, 검정 잉크, 절제된 빨강·주황·파랑을 사용한다. 참고 이미지의 종이와 온도계 인상은 활용하되 서예풍 장식은 복제하지 않는다.

## 3. 정보 구조와 내비게이션

### 3.1 화면

| 화면 | 진입 | 핵심 역할 |
|---|---|---|
| 게임 | 앱 실행, 딥링크, 새 게임 | 시드 확인, 추측, 힌트, 포기, 결과 확인 |
| 전체 순위 | 게임 종료 후 `전체 순위 보기` | 1위부터 전체 사전 순위를 점진적으로 탐색 |

특정 시드 선택은 게임 화면 위의 네이티브 `Modal`로 제공한다. MVP에는 탭 바나 햄버거 메뉴를 추가하지 않는다.

### 3.2 딥링크

- 공유 링크에는 `seed`와 게임 데이터 `version`을 포함한다.
- 같은 `seed + version`은 같은 문제를 연다.
- 지원하지 않는 버전은 조용히 새 문제로 바꾸지 않고 안내와 `랜덤 새 게임` 행동을 제공한다.
- 진행 중 다른 시드로 이동하면 `현재 게임을 나가고 다른 시드를 열까요?` 확인창을 표시한다. 추측이 없는 게임이나 이미 종료한 게임은 확인 없이 이동한다.

## 4. 게임 화면

게임 화면은 하나의 세로 `FlatList`를 사용한다. 고정 헤더와 중첩 스크롤을 피하고, 목록의 `ListHeaderComponent`에 상태 카드와 요약을 배치한다. 게임 진행 중에는 입력기를 화면 아래에 고정한다.

### 4.1 상단 영역

- 상태 표시줄과 상단 safe area 아래 최소 8dp 여백
- 높이 52dp, 좌우 16dp(400dp 이상은 20dp)
- 왼쪽: `뜨겁고 차갑게` 워드마크
  - `뜨겁고`는 hot, `차갑게`는 cold
  - 한 줄 유지, 18sp/800
- 오른쪽: 공유 아이콘 버튼, 48×48dp
  - 플레이 중에는 시드 초대 링크를 공유한다.
  - 종료 후에는 결과 문자열을 공유한다.

헤더 아래에는 시드 버튼을 둔다.

- `시드 #123456789` 라벨과 아래 방향 아이콘
- 최소 높이 44dp, 숫자는 가능한 경우 tabular 숫자
- 탭하면 시드 선택 Modal을 연다.

### 4.2 최고 기록 카드

추측 전에는 간단한 게임 설명, 추측 후에는 최고 기록을 표시한다.

**추측 전**

- 제목: `비밀 단어를 찾아보세요`
- 설명: `의미가 가까울수록 순위 숫자가 작아져요.`
- 파랑→중립→주황→빨강 온도 트랙과 `차가움 / 뜨거움` 라벨

**추측 후**

- 보조 라벨: `최고 기록`
- 숫자: `{rank}위`, 40sp/800, 한 줄
- 온도 한글 라벨과 온도계 아이콘
- `시도 {n}회 · 힌트 {n}/3`
- 현재 최고 기록에 맞는 4dp 왼쪽 강조선

카드는 좌우 16dp, 안쪽 20dp, radius 20dp를 사용한다. 화면 너비가 360dp일 때도 순위와 단위가 줄바꿈되지 않아야 한다.

### 4.3 추측 목록

- 제목: `추측한 단어`
- 오른쪽 보조 정보: `{n}개`
- 추측이 여러 개여도 1위에 가까운 순서로 정렬한다.
- 행 높이 최소 68dp, 좌우 16dp
- 왼쪽: 4dp 온도 강조선, 단어, 선택적 `힌트` 배지
- 오른쪽: `{rank}위`와 한글 온도 라벨
- 10,000 이상 순위도 잘리지 않도록 오른쪽 숫자 영역을 최소 96dp 확보한다.
- 힌트 행은 파란 테두리의 `힌트` 배지를 추가하되 목록 정렬 규칙은 동일하다.

온도 구간은 현재 게임 규칙을 그대로 사용한다.

| 순위 | 라벨 | 강조색 |
|---:|---|---|
| 1 | 정답 | hot |
| 2–10 | 매우 뜨거움 | hot |
| 11–100 | 뜨거움 | warm |
| 101–1,000 | 따뜻함 | warm과 inkSoft 조합 |
| 1,001 이후 | 차가움 | cold |

### 4.4 빈 상태

첫 추측 전에는 목록 대신 최소 높이 144dp의 빈 카드를 표시한다.

- 원형 테두리 안 온도계 아이콘
- `첫 단어를 입력하면 순위가 쌓여요.`
- `예: 바다, 기술, 마음`처럼 정답을 암시할 수 있는 고정 예시는 넣지 않는다.

### 4.5 하단 입력기

입력기는 게임 진행 중 화면 아래에 고정한다.

- 배경: surface 96%, 위쪽 1dp line
- 좌우 16dp, 위 10dp, 아래 `max(10dp, bottom safe area)`
- 첫 줄: 입력 필드 + `추측` 버튼
  - 입력 필드 높이 52dp, radius 14dp
  - placeholder: `단어를 입력하세요`
  - 한글 완성형, 공백 제거 후 최대 20자
  - 자동 대문자/자동 수정/자동 완성 끄기
  - `returnKeyType="done"`, 제출 후 입력 비우고 포커스 유지
  - 버튼 높이 52dp, 최소 너비 76dp, ink 배경
- 둘째 줄: `힌트 보기 {n}/3`과 `포기하고 정답 보기`
  - 각 터치 영역 최소 48dp
  - 힌트는 coldDark, 포기는 muted 텍스트

키보드가 닫혀 있을 때는 입력 도움말을 한 줄 표시한다. 키보드가 열리면 도움말을 숨겨 360dp 화면에서도 추측 목록 한 행 이상이 보이도록 한다. 오류 메시지는 도움말보다 우선하며 키보드 상태와 관계없이 표시한다.

### 4.6 키보드와 safe area

- `SafeAreaView`의 top/bottom inset을 적용한다.
- Android는 키보드 resize/inset을 사용하고, iOS는 `KeyboardAvoidingView`의 padding 또는 position을 사용한다.
- 입력 필드 포커스 시 가려진 목록 영역만 줄어들고 전체 화면이 위로 이중 이동하지 않아야 한다.
- 키보드가 열린 상태에서 추측 제출, 힌트, 오류 확인이 모두 가능해야 한다.
- 목록을 탭하거나 아래로 드래그하면 키보드를 닫되, 버튼 탭은 첫 탭에서 동작해야 한다(`keyboardShouldPersistTaps="handled"`).
- 화면 회전은 MVP에서 세로 고정이다.

## 5. 시드 선택 Modal

- 제목: `게임 시드`
- 설명: `같은 시드는 누구에게나 같은 문제를 만들어요.`
- 숫자 입력: 0–4,294,967,295, 숫자 키패드
- 주 버튼: `이 시드 열기`
- 보조 버튼: 셔플 아이콘 + `랜덤 새 게임`
- 닫기 아이콘 버튼: 48×48dp

잘못된 범위나 형식은 입력 아래에 `0부터 4,294,967,295 사이의 정수를 입력해 주세요.`라고 표시하고 Modal을 유지한다. 새 게임 선택 시 현재 게임을 나가야 한다면 Modal을 닫기 전에 확인 Alert를 표시한다.

## 6. 상태와 피드백

### 6.1 상태 표

| 상태 | 화면 처리 | 문구/행동 |
|---|---|---|
| 첫 게임 로딩 | 크림 배경의 전체 화면, 중앙 작은 spinner | `시드 게임을 준비하고 있어요` |
| 저장 기록 복원 | skeleton 대신 동일 로딩 화면 유지 | 복원 완료 후 한 번에 게임 표시 |
| 8초 이상 첫 계산 | 로딩을 계속 유지하고 보조 문구만 변경 | `순위를 계산하고 있어요. 첫 계산은 조금 더 걸릴 수 있어요.` |
| 실제 타임아웃/초기 네트워크 실패 | 전체 화면 오류 카드 | `게임 서버에 연결하지 못했어요.` + `다시 시도` |
| 추측 판정 중 | 추측 버튼 안 spinner, 입력·힌트·포기 비활성 | `순위를 확인하는 중` 접근성 라벨 |
| 정상 추측 | 입력 비움, 행 추가, 최고 기록 갱신 | selection 햅틱 |
| 최고 기록 갱신 | 최고 기록 카드 숫자만 짧게 강조 | light 햅틱 |
| 미등록 단어 | 입력 아래 inline 오류, 입력값과 포커스 유지 | `사전에 없는 단어예요. 다른 표현을 시도해 보세요.` |
| 형식 오류 | 입력 아래 inline 오류 | `완성된 한글 단어만 입력해 주세요.` |
| 중복 입력 | 입력 아래 inline 오류, 해당 기존 행을 잠깐 강조 | `이미 확인한 단어예요.` |
| 진행 중 네트워크 오류 | 기존 목록 유지, 입력기 위 inline banner | `서버에 연결하지 못했어요.` + `다시 시도` |
| 힌트 로딩 | 힌트 버튼 안 spinner, 나머지 위험 동작 비활성 | `더 가까운 단어를 찾는 중` |
| 힌트 성공 | `힌트` 배지가 붙은 행 추가 | light 햅틱, 힌트 카운트 갱신 |
| 힌트 소진 | 힌트 버튼 비활성 | `힌트 3/3` |
| 정답 | 성공 결과 카드로 전환 | `정답! {word}` + success 햅틱 |
| 포기 확인 | 네이티브 Alert | `정답을 공개하면 이 게임은 끝나요.` / `계속하기` / `정답 보기` |
| 포기 완료 | 중립 결과 카드로 전환 | `정답은 {word}` + medium 햅틱 |
| 공유 메뉴 열기 | OS 공유 시트 | 취소는 오류로 알리지 않음 |
| 공유 완료 | 화면 아래 toast, 2초 | `공유할 내용을 준비했어요.` 또는 `결과를 복사했어요.` |
| 공유 실패 | toast와 재시도 가능 버튼 | `공유하지 못했어요. 다시 시도해 주세요.` |

초기 로딩이 약 8초를 넘겨도 진행 중 요청을 취소하거나 중복 요청을 만들지 않는다. 위의 장시간 계산 문구와 spinner만 유지하고, 실제 실패 또는 네트워크 타임아웃이 확정된 뒤에만 `다시 시도`를 표시한다. 진행 중 오류는 전체 화면으로 덮지 않는다.

### 6.2 종료 화면

정답 또는 포기 뒤에는 하단 입력기를 제거하고 결과 행동 카드를 목록 상단에 표시한다.

**정답 카드**

- hotDark→hot→warm의 완만한 배경 또는 접근성 대비를 만족하는 hot 단색
- 흰색 `정답!`, `{word}`, `{n}번 만에 찾았어요`

**포기 카드**

- surface 배경, dashed line 테두리
- muted `이 시드의 정답`, ink `{word}`, `다음 게임에서 다시 도전해 보세요.`

**행동 순서**

1. `랜덤 새 게임` — 주 버튼, 전체 너비
2. `결과 공유` — 보조 버튼
3. `전체 순위 보기` — 테두리/텍스트 버튼

특정 시드 재도전은 MVP에서 제공하지 않는다. 같은 시드를 열면 종료 기록을 복원한다.

## 7. 전체 순위 화면

전체 순위는 게임 종료 후에만 진입할 수 있는 별도 화면이다.

### 7.1 상단

- 뒤로가기 48×48dp
- 제목: `전체 순위`
- 보조 문구: `시드 #{seed}`
- 결과 요약 카드: `정답 {word}` / `총 {total}개 단어`
- 시스템 뒤로가기, 상단 뒤로가기, iOS 뒤로가기 제스처는 모두 종료된 게임 화면의 기존 상태로 돌아간다.

### 7.2 목록과 페이지 조회

- `FlatList` 한 개를 사용하고 1위부터 오름차순으로 표시한다.
- API는 `offset`과 `limit`을 사용해 200개 단위로 조회한다.
- 첫 페이지 skeleton은 8개 행만 보여 주고 실제 단어 길이를 흉내 내지 않는다.
- 끝에 가까워지면 다음 페이지를 한 번만 요청한다.
- 다음 페이지 실패 시 기존 행을 유지하고 `더 불러오지 못했어요`와 `다시 시도` footer를 표시한다.
- 마지막 페이지에는 `전체 순위를 모두 불러왔어요`를 표시한다.
- 같은 offset 중복 요청과 중복 행을 막는다.
- 행은 `{rank}위`, `{word}`, 온도 라벨을 포함한다.
- 1–10위는 hot의 6% tint, 11–100위는 warm의 6% tint, 나머지는 surface를 사용한다. 색만으로 구간을 구별하지 않는다.

280,804개를 기기에 한꺼번에 보관하거나 한 응답으로 받지 않는다. 화면을 나가면 목록 데이터는 메모리에서 해제할 수 있으며 게임 결과는 유지한다.

### 7.3 전체 순위 상태

| 상태 | 처리 |
|---|---|
| 첫 페이지 로딩 | 헤더는 유지하고 8행 skeleton |
| 첫 페이지 실패 | 중앙 오류 카드 + `다시 시도` + `게임으로 돌아가기` |
| 추가 로딩 | ListFooter spinner + `다음 200개를 불러오는 중…` |
| 추가 실패 | 기존 행 유지 + `더 불러오지 못했어요` + `다시 시도` |
| 끝 | `전체 순위를 모두 불러왔어요` |
| 빈 응답 | `순위 데이터가 없어요.` + 재시도 |

## 8. 디자인 토큰

### 8.1 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| paper | `#F5F2EB` | 앱 배경 |
| surface | `#FFFEFA` | 카드, 입력기 |
| ink | `#17191F` | 주 텍스트, 주 버튼 |
| inkSoft | `#353943` | 보조 강조 텍스트 |
| muted | `#686D78` | 설명, 비활성 전경 |
| line | `#DEDBD3` | 구분선, 테두리 |
| hot | `#E2442F` | 정답, 매우 뜨거움 |
| hotDark | `#B92A1A` | hot 위 대비, 오류 텍스트 |
| warm | `#ED8A21` | 뜨거움, 따뜻함 |
| cold | `#2376D2` | 차가움, 포커스, 정보 |
| coldDark | `#175A9E` | 링크, 힌트 텍스트 |

필요한 투명도는 위 색상에서 계산한다. 새로운 브랜드색은 추가하지 않는다.

### 8.2 타이포그래피

- 기본: Pretendard 계열 Korean sans
- 폰트 자산을 번들하지 않은 MVP 빌드에서는 플랫폼 시스템 Korean sans를 사용한다.
- 굵기: 400 본문, 600 라벨/버튼, 800 브랜드/순위/결과

| 스타일 | 크기/행간 | 용도 |
|---|---|---|
| caption | 12/16sp | 보조 정보, 배지 |
| bodySmall | 14/20sp | 설명, 오류, 온도 라벨 |
| body | 16/24sp | 입력, 목록 단어 |
| titleSmall | 20/26sp | 화면/카드 제목 |
| result | 28/36sp | 정답 단어 |
| rankHero | 40/44sp | 최고 순위 |

순위와 시드 숫자는 가능한 경우 tabular 숫자를 사용한다. 글자 크기 확대 200%에서도 핵심 행동과 텍스트가 잘리지 않아야 하며, 필요하면 행 높이를 늘린다.

### 8.3 간격, 모서리, 높이

- 간격: 4, 8, 12, 16, 20, 24, 32dp
- 화면 gutter: 360–399dp는 16dp, 400–430dp는 20dp
- radius: 8(배지), 12(작은 카드), 14(입력/버튼), 20(주 카드), 999(pill)
- 터치 영역: 최소 48×48dp
- 주 입력/버튼: 높이 52dp
- 목록 행: 최소 68dp

### 8.4 그림자

- 기본 카드는 테두리만 사용한다.
- 최고 기록/종료 카드에만 낮은 그림자를 허용한다.
  - Android: elevation 1 또는 3
  - iOS: y 8, blur 24, `rgba(53,45,30,0.10)`
- 여러 그림자 단계나 강한 유리 효과를 사용하지 않는다.

## 9. 아이콘과 그래픽

### 9.1 앱 내부 아이콘

Expo에 포함된 `@expo/vector-icons`의 한 계열만 사용한다. MaterialCommunityIcons를 우선한다.

| 행동 | 아이콘 방향 |
|---|---|
| 공유 | `share-variant-outline` |
| 힌트 | `lightbulb-outline` |
| 포기 | `flag-outline` |
| 랜덤 새 게임 | `shuffle-variant` |
| 온도 | `thermometer` 또는 `thermometer-lines` |
| 뒤로가기 | `arrow-left` |
| 닫기 | `close` |

아이콘만 있는 버튼은 접근성 라벨을 제공한다. 이모지, 텍스트 기호, 손으로 만든 SVG는 사용하지 않는다.

### 9.2 앱 아이콘 방향

- 크림색 바탕 위 세로 온도계 한 개
- 아래는 cold 파랑, 위는 hot 빨강, 중앙은 얇은 잉크 선
- 작은 크기에서도 읽히도록 글자와 세부 눈금을 넣지 않는다.
- adaptive icon foreground는 안전 영역 안에 두고 배경색은 paper로 고정한다.

### 9.3 Play 스토어 그래픽 방향

- 앱 아이콘: 512×512 PNG
- feature graphic: 1024×500, 왼쪽 파랑→오른쪽 빨강 온도 트랙과 `단어의 온도를 따라 정답까지` 문구
- 세로 스크린샷 4–6장, 9:16
  1. 단어를 입력하고 정확한 순위 확인
  2. 높은 순위부터 정렬되는 추측 목록
  3. 현재 기록보다 가까운 적응형 힌트
  4. 시드 공유로 같은 문제 경쟁
  5. 정답 후 전체 순위 탐색
- 스크린샷 배경은 paper, 큰 설명은 ink, 핵심 단어만 hot/cold로 강조한다.
- 실제 앱 캡처를 사용하고 기능을 오해하게 하는 합성 데이터나 온라인 경쟁 화면을 넣지 않는다.

## 10. 모션과 햅틱

### 10.1 모션

- 추측 행 추가: 180ms, opacity 0→1 + translateY 6→0
- 최고 기록 갱신: 220ms, 숫자 scale 1→1.03→1
- Modal: 플랫폼 기본 전환
- toast: 160ms fade/slide, 2초 유지
- 긴 연속 애니메이션, 배경 입자, 진동하는 온도계는 사용하지 않는다.
- 시스템의 모션 감소 설정이 켜져 있으면 전환을 즉시 적용한다.

### 10.2 햅틱

| 사건 | 강도 |
|---|---|
| 정상 추측 판정 | selection |
| 최고 기록 갱신/힌트 성공 | light impact |
| 정답 | success notification |
| 형식·미등록·네트워크 오류 | error notification |
| 포기 확인 | medium impact |

로딩 시작, 스크롤, 일반 버튼 탭에는 햅틱을 넣지 않는다. 기기 또는 설정이 지원하지 않으면 조용히 생략한다.

## 11. 접근성

- 본문과 조작 요소는 WCAG AA 대비를 목표로 한다.
- 색상과 함께 순위, 온도 라벨, 아이콘/강조선을 제공한다.
- 모든 아이콘 버튼은 한국어 접근성 라벨과 역할을 가진다.
- 동적 결과는 `accessibilityLiveRegion="polite"` 또는 동등한 알림을 사용한다.
- 정답, 오류, 공유 완료는 화면 리더가 한 번만 읽도록 중복 live region을 피한다.
- 추측 행 읽기 순서: `{word}, {rank}위, {temperature}, 힌트 여부`.
- 전체 순위 행 읽기 순서: `{rank}위, {word}, {temperature}`.
- 터치 대상은 최소 48dp이며 아이콘 시각 크기는 20–24dp를 사용한다.
- 글자 확대 시 버튼 텍스트를 말줄임하지 않고 높이가 늘어나게 한다.
- 고대비/다크 모드는 MVP 범위 밖이다. 시스템 다크 모드에서도 앱은 명시적으로 light 테마를 유지한다.

## 12. 구현 수용 기준

- 360×640dp와 430×932dp 세로 화면에서 가로 스크롤이나 잘린 버튼이 없다.
- Android 한국어 키보드가 열린 상태에서 입력 필드, 추측 버튼, 오류, 힌트가 가려지지 않는다.
- 추측 목록은 순위 오름차순이며 6자리 순위도 한 줄로 보인다.
- 미등록, 중복, 네트워크 오류 뒤 입력 내용과 기존 목록이 보존된다.
- 정답/포기 뒤 입력기가 사라지고 새 게임, 공유, 전체 순위 행동이 보인다.
- 전체 순위는 첫 응답에 모든 데이터를 받지 않고 200개 단위로 추가 조회한다.
- 추가 페이지 실패 뒤 이미 불러온 순위를 계속 볼 수 있고 footer에서 재시도할 수 있다.
- 색을 보지 않아도 순위와 온도 상태를 이해할 수 있다.
- 화면 리더와 글자 크기 확대, 모션 감소 설정에서 핵심 게임 흐름을 완료할 수 있다.

## 13. 개발 협업 메모

- 게임 API의 추측/힌트/정답 응답은 종료 여부와 정답 메타만 반환하고 전체 순위는 별도 페이지 API로 조회한다.
- 전체 순위 기본 limit은 200으로 제안한다. 서버나 실제 성능 측정 결과에 따라 100–500 범위에서 조정할 수 있으나 한 번에 전체 목록을 전송하지 않는다.
- Pretendard 파일을 앱에 포함하지 않는 첫 빌드는 시스템 Korean sans를 사용해 Expo Go 호환성을 우선한다.
- 앱 내부 그래픽은 벡터 아이콘과 단순 색상 면으로 구성하고, 스토어용 래스터 그래픽은 기능 구현 안정화 후 별도 제작한다.
