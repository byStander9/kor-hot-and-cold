# 개인정보처리방침 초안

> 상태: Play 제출 전 운영자명, 문의 이메일, 운영 호스팅 사업자, 로그 보유기간과 시행일을 확정해야 하는 초안입니다. 미확정 표시를 제거하기 전에는 최종 개인정보처리방침 URL로 사용하지 않습니다.

`뜨겁고 차갑게`(Android package: `com.bystander9.korhotandcold`)의 운영자 `[운영자명 확정 필요]`는 게임 제공에 필요한 최소한의 정보를 다음과 같이 처리합니다.

## 1. 처리하는 정보

### 게임 기능을 위해 서버로 전송되는 정보

- 숫자 게임 시드
- 사용자가 입력한 추측어
- 힌트, 정답 공개, 전체 순위 요청

이 정보는 정답 판정, 의미 근접 순위 계산, 힌트와 전체 순위 제공에 사용됩니다. 앱은 회원가입이나 로그인을 제공하지 않으며 입력 정보를 계정과 연결하지 않습니다.

### 기기에만 저장되는 정보

- 시드별 추측과 순위
- 힌트 사용 횟수
- 정답 또는 포기 상태

이 진행 정보는 기기의 앱 로컬 저장소에 보관되며 운영 서버로 동기화되지 않습니다. 사용자는 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하여 지울 수 있습니다.

### 호스팅 과정에서 처리될 수 있는 정보

게임 서버의 호스팅 사업자는 서비스 보안, 트래픽 전달, 장애 대응을 위해 다음 표준 접근 로그를 자동 처리할 수 있습니다.

- IP 주소
- 요청 URL과 요청 시각
- User-Agent 등 기기·브라우저 식별 정보

`[운영 호스팅 사업자와 실제 로그 항목 확정 필요]`

## 2. 이용 목적

- 게임 기능 제공과 요청 처리
- 서버 장애 진단과 보안 대응
- 법적 의무 준수

로그인, 맞춤형 광고, 마케팅, 사용자 행동 분석, 푸시 알림 목적으로 사용하지 않습니다.

## 3. 보유와 삭제

앱 서버 구현은 계정별 플레이 기록을 생성하거나 게임 요청을 데이터베이스에 저장하지 않습니다. 판정에 필요한 요청은 응답 생성 과정에서 처리됩니다.

호스팅 사업자가 생성하는 접근 로그의 보유기간과 삭제 절차는 실제 운영 설정과 계약을 확인한 뒤 다음 항목에 명시합니다.

- 접근 로그 보유기간: `[확정 필요]`
- 삭제 또는 열람 요청 방법: `[문의 이메일 확정 필요]`
- 법적 의무로 더 오래 보관하는 예외: `[해당 여부 확정 필요]`

## 4. 제3자 처리와 국외 이전

운영 서버가 Hugging Face Spaces 등 외부 호스팅을 사용하면 요청 정보와 접근 로그가 해당 사업자의 인프라에서 처리될 수 있습니다. 최종 호스팅 확정 후 사업자명, 처리 국가, 이전 항목, 목적, 시점과 방법, 보유기간을 정확히 기재합니다.

`[Hugging Face 운영 정책 및 리전 확인 필요]`

## 5. 사용자의 선택과 권리

- 앱 데이터는 Android 설정 또는 앱 제거로 삭제할 수 있습니다.
- 서버 접근 로그의 열람·삭제 가능 범위는 운영 호스팅 정책과 법적 의무에 따라 달라질 수 있습니다.
- 개인정보 관련 문의: `[공개 문의 이메일 확정 필요]`

## 6. 데이터와 모델 출처

게임은 표준국어대사전 공개 데이터, `multilingual-e5-small`, Kiwi 한국어 형태소 분석기를 활용합니다. 외부 데이터와 모델의 저작자, 고정 리비전, 라이선스는 [데이터·모델 출처 문서](../../DATA_SOURCES.md)를 따릅니다.
