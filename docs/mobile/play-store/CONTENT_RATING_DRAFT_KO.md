# Google Play 대상 연령·IARC 답변 근거 초안

작성일: 2026년 8월 11일  
대상 게임 데이터: v2

> Play Console의 질문과 지역별 등급은 제출 시점에 달라질 수 있습니다. 이 문서는 답변을 대신 제출하는 양식이 아니라, 실제 앱 콘텐츠를 누락 없이 설명하기 위한 근거입니다.

## 대상 연령 권고

- 초기 Target audience: `16–17`, `18+`
- `15세 이하` 그룹은 초기 출시에서 선택하지 않음
- 마케팅 문구와 그래픽도 아동·가족용으로 표현하지 않음

무작위 정답과 자동 힌트는 검수된 3,186개 일반어 allowlist에서만 선택합니다. 하지만 추측 사전은 280,804개 표제어를 유지하며, 게임 종료 뒤 경고에 동의하면 성인·비속어·폭력·약물 관련 명시 차단어를 포함한 전체 순위를 볼 수 있습니다. 이 opt-in은 연령 확인이나 보호자 통제가 아니므로 대상 연령을 낮추는 근거로 사용하지 않습니다.

## IARC에서 사실대로 신고할 콘텐츠

Console에 표시되는 실제 질문과 빈도 선택지를 읽고 다음 사실을 빠뜨리지 않습니다.

| 설문 주제 | 실제 앱 상태 | 답변 근거 |
|---|---|---|
| 비속어·거친 언어 | 텍스트 사전에 존재할 수 있음 | 기본 순위에서는 명시 목록을 숨기지만 종료 뒤 경고·opt-in으로 표시 가능 |
| 성적·성인 주제 | 일부 사전 표제어가 텍스트로 존재할 수 있음 | 이미지·행위 묘사는 없지만 opt-in 전체 순위의 단어 자체는 접근 가능 |
| 폭력·자해·범죄 | 일부 관련 표제어가 텍스트로 존재할 수 있음 | 그래픽 연출은 없지만 단어가 순위표에 나타날 수 있음 |
| 약물·담배·음주 | 일부 관련 표제어가 텍스트로 존재할 수 있음 | 사용을 조장하거나 보상하지 않지만 단어가 나타날 수 있음 |
| 도박 | 도박 기능·모의 도박·현금성 보상 없음 | 관련 표제어가 사전에 있을 수 있다는 점과 게임 기능을 구분해 질문 문구대로 답함 |
| 사용자 상호작용 | 채팅·게시·사용자 간 콘텐츠 공유 없음 | 추측어는 판정을 위해 서버에 보내지만 다른 사용자에게 공개하지 않음 |
| 구매·광고 | 결제·확률형 아이템·광고 없음 | 현재 코드와 SDK 기준 |

단순 단어 노출인지 묘사·조장인지 구분하되, 경고 뒤 볼 수 있다는 이유로 콘텐츠가 “없음”이라고 답하지 않습니다. 빈도는 명시 차단 목록의 규모, 접근 단계와 실제 Console 정의를 대조해 가장 가까운 보수적 선택지를 고릅니다.

## 제출 전 증거 확인

- [ ] v2 정답 공개를 여러 시드에서 표본 검사하고 모두 answer pool 소속인지 확인
- [ ] 자동 힌트가 answer pool 소속이며 현재 최고 순위보다 가까운지 확인
- [ ] 기본 전체 순위 API와 화면에서 명시 차단어가 제외되는지 확인
- [ ] 종료 뒤 경고를 취소하면 민감 단어가 표시되지 않는지 확인
- [ ] 동의하면 전체 사전이 표시되고 선택이 저장·공유되지 않는지 확인
- [ ] 스토어 설명·스크린샷이 민감 단어 opt-in을 숨기거나 아동용으로 오해시키지 않는지 확인
- [ ] Play Console이 산출한 지역별 등급을 확인하고 예상보다 낮으면 설문 답변을 다시 검토

정답 풀 생성·검수 방법과 잔여 위험은 [정답 어휘 안전 정책](../../data/ANSWER_SAFETY_POLICY_KO.md)을 따릅니다.
