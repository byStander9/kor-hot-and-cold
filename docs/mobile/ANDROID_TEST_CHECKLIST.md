# Android 실기기 테스트 체크리스트

대상은 Expo Go를 설치한 Android 스마트폰이며, 최소 한 번은 360×640dp에 가까운 작은 기기와 430×932dp에 가까운 큰 기기에서 확인합니다. 테스트 전 PC와 스마트폰을 같은 Wi-Fi에 연결하고 API 서버를 `0.0.0.0:3000`으로 실행합니다.

## 실행과 연결

- [ ] 앱 시작 후 30초 안에 랜덤 시드 게임이 열린다.
- [ ] 8초 이상 걸릴 때 요청을 중복하지 않고 장시간 계산 문구가 표시된다.
- [ ] Wi-Fi를 끊으면 기존 추측 목록을 유지한 채 재시도 배너가 표시된다.
- [ ] Wi-Fi 복구 후 `다시 시도`로 같은 동작을 완료한다.
- [ ] 앱을 완전히 닫았다 열어도 같은 시드의 추측·힌트·종료 상태가 복원된다.

## 한국어 키보드와 작은 화면

- [ ] 360×640dp 세로 화면에서 한국어 키보드를 열어도 입력·추측·힌트·오류가 함께 보인다.
- [ ] `사랑`, `바다가`, `걷는다`처럼 한글 조합·조사·활용형 입력 중 글자가 중간에 잘리지 않는다.
- [ ] 키보드의 완료 키로 제출한 뒤 입력이 비워지고 포커스는 유지된다.
- [ ] 미등록 단어, 영문, 중복 단어 오류 뒤 입력값과 기존 목록이 보존된다.
- [ ] 목록을 드래그하면 키보드가 닫히고 버튼은 첫 탭에 작동한다.
- [ ] 숫자 시드 Modal에서 숫자 키패드가 뜨고 최대 시드 범위 오류를 읽을 수 있다.

## 게임 기능

- [ ] 추측 결과가 입력 순서가 아니라 순위 오름차순으로 표시된다.
- [ ] 힌트가 현재 최고 기록보다 더 높은 순위를 주고 3회 뒤 비활성화된다.
- [ ] 포기 확인창에서 취소하면 게임이 계속되고 정답 보기를 누르면 입력기가 사라진다.
- [ ] 정답 후 랜덤 새 게임, 결과 공유, 전체 순위 행동이 모두 보인다.
- [ ] 진행 중 다른 시드로 이동할 때 확인창이 표시되고 종료 게임은 확인 없이 이동한다.
- [ ] 시드 공유 링크에 `seed`와 `v`가 포함되고 같은 문제를 연다.
- [ ] 공유 시트를 취소해도 오류 토스트가 표시되지 않는다.

## 전체 순위와 성능

- [ ] 전체 순위 첫 응답은 200개이며 스크롤할 때만 다음 200개를 요청한다.
- [ ] 추가 요청 중 같은 offset을 중복 호출하지 않는다.
- [ ] 다음 페이지 실패 뒤 기존 행이 남고 footer에서 재시도할 수 있다.
- [ ] 시스템 뒤로가기와 상단 뒤로가기가 종료된 게임 상태로 돌아간다.
- [ ] 1위, 6자리 순위, 긴 단어와 온도 라벨이 가로로 잘리지 않는다.

## 접근성·시스템 UI

- [ ] TalkBack이 추측 행을 `단어, 순위, 온도, 힌트 여부` 순으로 읽는다.
- [ ] 글자 크기 200%에서 주요 버튼 문구가 말줄임되지 않는다.
- [ ] 모션 감소 설정에서도 핵심 게임 흐름을 완료할 수 있다.
- [ ] 상태 표시줄·내비게이션 바·제스처 영역이 헤더와 종료 화면을 가리지 않는다.
- [ ] 정답·오류·공유 완료가 중복 낭독되지 않는다.
- [ ] 햅틱을 끈 기기나 지원하지 않는 기기에서도 오류 없이 진행된다.

## 배포 전 기록

- [ ] 테스트 기기 모델, Android 버전, 화면 크기, 키보드 앱을 기록한다.
- [ ] 초기·키보드 열림·미등록 오류·네트워크 재시도·정답·포기·전체 순위 화면을 캡처한다.
- [ ] 운영 HTTPS API와 공유 URL에서 다시 전체 흐름을 실행한다.
- [ ] 앱 내 출처 안내와 스토어 설명에 외부 데이터·모델의 저작자와 라이선스를 고지한다.
- [ ] Play Console 데이터 보안 답변과 개인정보처리방침이 실제 서버 로그·분석 도구 동작과 일치하는지 확인한다.
