# 임베딩 모델 1차 비교

평가일: 2026-08-06

## 목적

초기 기준 평가로 한국어기초사전 계열의 표제어·품사·뜻풀이를 사용해 4,851개 어휘를 임베딩하고, 단어 게임에서 납득할 수 있는 근접 순위가 나오는지 확인했다. 이후 같은 모델과 입력 형식을 유지한 채 표준국어대사전 변환본을 병합해 현재 게임 데이터는 280,804개로 확장했다.

## 비교 모델

| 모델 | 라이선스 | 고정 리비전 | 입력 |
|---|---|---|---|
| `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` | Apache-2.0 | `e8f8c211226b894fcb81acc59f3b34ba3efd5f42` | 표제어 + 품사 + 뜻풀이 |
| `intfloat/multilingual-e5-small` | MIT | `614241f622f53c4eeff9890bdc4f31cfecc418b3` | `query:` + 표제어 + 품사 + 뜻풀이 |

두 모델 모두 Hugging Face Hub에서 고정 리비전으로 내려받았으며 가중치는 GitHub 저장소에 포함하지 않았다.

## 관찰 결과

MiniLM은 `학교`, `음식`, `겨울`, `병원`에서는 좋은 결과를 냈지만 일부 정답에서 뜻풀이 문장의 표면적 특징에 크게 흔들렸다. 예를 들어 `영화`의 상위권에 `울산`, `빌딩`, `대전`, `연도`가 포함되어 출시 문제로 사용하기 어려웠다.

E5는 같은 정답의 상위권을 `촬영`, `영상`, `제목`, `미술`, `상영`, `관람`, `화면`, `예술`, `장면`, `연출`로 개선했다. 다른 대표 정답에서도 다음과 같이 탐색 가능한 경로가 나타났다.

| 정답 | E5 상위 근접어 예시 |
|---|---|
| 바다 | 바닷가, 해변, 바닷물, 물가, 해안, 앞바다, 육지, 해물 |
| 학교 | 학원, 교재, 수업, 교과서, 교육, 중학교, 학생, 강의 |
| 음식 | 음식물, 식품, 식사, 식량, 식료품, 외식, 간식, 요리법 |
| 병원 | 환자, 간호사, 병실, 의사, 응급실, 치료, 입원, 내과 |
| 컴퓨터 | 복사기, 정보, 프린터, 노트북, 온라인, 입력, 계산기, 인터넷 |
| 겨울 | 가을, 겨울철, 여름, 사계절, 늦겨울, 추위, 계절, 봄 |

## 결정

데모 게임 데이터는 `intfloat/multilingual-e5-small`을 사용한다. 이유는 다음과 같다.

- Hub에 MIT 라이선스가 명시되어 있다.
- MiniLM과 크기가 비슷해 로컬 생성 비용이 과도하게 늘지 않는다.
- 이번 20개 정답의 수동 비교에서 뜻풀이 기반 근접어가 더 일관됐다.

이 결정은 모델의 일반적인 우열을 뜻하지 않으며 현재 어휘집과 입력 템플릿에 한정된다.

## 한계와 다음 검증

- 20개 정답의 개발자 관찰만 수행했으므로 블라인드 다인 평가가 아니다.
- `친구`, `동물`처럼 의미가 넓은 정답은 상위 근접어가 다소 산만하다.
- 정의 임베딩은 사전 뜻풀이 방식의 영향을 받는다.
- 실제 플레이에서 정답률, 중앙 추측 횟수, OOV 비율을 측정해야 한다.
- 모델 또는 입력 템플릿이 바뀌면 모든 문제를 다시 검수해야 한다.

정식 문제 세트로 승격하기 전 각 문제의 상위 30개를 최소 3명이 블라인드 평가하고, 관련성 0점 비율이 10%를 넘는 문제는 제외한다.
