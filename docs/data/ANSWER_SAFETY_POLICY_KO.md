# 정답 어휘 안전 정책

## 목적

게임의 추측 사전은 28만여 개 단어를 유지하되, 무작위 정답은 별도의 검수된 allowlist에서만 고릅니다. 공개 사전의 난이도·의미 범주는 콘텐츠 안전 등급이 아니므로 그 메타데이터만으로 정답 안전성을 보장하지 않습니다.

## 생성 기준

`data/safety/answer-policy.json`과 `pipeline`의 `build-answer-pool` 명령이 다음 조건을 모두 만족하는 어휘 ID를 `data/demo/answer-pool.json`에 기록합니다.

- 초급 또는 중급
- 의미 범주가 있는 단어
- 명사·동사·형용사 중 하나를 포함
- 한글 2~6자
- 제외 범주와 명시적 정답 제외 목록에 해당하지 않음

결과 파일은 원문 단어를 중복 저장하지 않고 정렬된 사전 ID, 개수, SHA-256만 기록합니다. `gameVersion`은 시드와 정답 매핑 계약, `lexiconVersion`은 사전·임베딩 계약이라 서로 독립적으로 관리합니다.

## 출처와 검수

사전 출처와 고정 revision은 `data/demo/README.md`에 기록되어 있습니다. 2026-08-11에 조건 필터 결과를 의미 범주별로 집계하고 성인·비속어·폭력·약물 관련 검색어로 재검토했습니다. 저장소의 명시 목록은 실제 차단에 필요한 최소 항목만 유지하며, 대량의 민감 단어 목록을 문서에 다시 싣지 않습니다.

새 사전이나 정책을 적용할 때는 생성 명령을 다시 실행하고 다음을 사람이 확인해야 합니다.

1. 새 후보와 제거 후보의 범주별 개수
2. 성인·비속어·폭력·약물 관련 검색 결과
3. 무작위 표본과 경계 사례
4. 개수·SHA-256 회귀 테스트의 의도적인 갱신

전체 순위에는 추측 사전의 민감 어휘가 남아 있을 수 있습니다. 기본 화면은 명시 목록을 제외하며, 종료 뒤 경고를 확인한 사용자가 로컬에서 선택한 경우에만 포함합니다. 이 정책은 자동 분류가 아니므로 출시 등급은 보수적으로 유지합니다.
